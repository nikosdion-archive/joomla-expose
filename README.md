# Expose plugin for Joomla!

Use Joomla! with [Expose by BeyondCode](https://expose.dev) more easily.

> [!IMPORTANT]
> This plugin is obsolete as it is no longer necessary. Go to Global Configuration and set Behind Load Balancer to Yes. Just make sure you do NOT use `$live_site` in your `configuration.php` file. The only reason this plugin ever existed is that very old Joomla 4.x versions did not have the Behind Load Balancer feature. As of September 1st, 2026 when I am archiving this repo, Joomla 4 is long dead, Joomla 5.4 is about to enter security-only releases, and Joomla 6 is in the middle of its release cycle. Every single version of Joomla supported by the J! project has the Behind Load Balancer feature, making this plugin obsolete.
